# 3.3V Voltage Regulator Circuit

**KiCad | AP2112K-3.3 | Power Supply Design**

## Project Overview

This project involves designing a 3.3V voltage regulator circuit using the AP2112K-3.3 Low Dropout (LDO) regulator.

The circuit schematic includes input and output capacitors for power supply filtering and stable voltage regulation.

## Main Component

- AP2112K-3.3 – 3.3V LDO Voltage Regulator
- Input capacitors
- Output capacitors
- Power input and output connections
